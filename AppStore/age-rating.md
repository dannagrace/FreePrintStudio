# FreePrint Studio Age Rating Answers

Use this file when completing the App Store Connect age rating questionnaire.

Expected global age rating: 4+

Rationale: FreePrint Studio is a local print-layout utility. It does not include objectionable content, social features, messaging, user-generated content publication, advertising, contests, gambling, commerce, or unrestricted web browsing.

## Content Descriptors

- Profanity or crude humor: None
- Mature or suggestive themes: None
- Horror or fear themes: None
- Medical or treatment information: None
- Alcohol, tobacco, drug use, or references: None
- Simulated gambling: None
- Sexual content or nudity: None
- Cartoon or fantasy violence: None
- Realistic violence: None
- Realistic violence with blood or gore: None

## In-App Controls and Capabilities

- User-generated content: None
- Messaging and chat: None
- Advertising: None
- Parental controls: None
- Age assurance: None
- Unrestricted web access: No
- Web links: Limited to the app privacy policy and support page from the About screen
- Gambling or contests: None
- In-app purchases: None

## Regional Notes

No region-specific rating override is expected based on the current feature set. Re-evaluate this file if the app later adds cloud upload, community sharing, messaging, ads, contests, purchases, or web browsing.
