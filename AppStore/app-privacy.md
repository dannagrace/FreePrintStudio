# FreePrint Studio App Privacy Answers

Use this file when completing App Privacy in App Store Connect.

## Privacy Policy URL

https://dannagrace.github.io/FreePrintStudio/privacy-policy.html

## Data Collection

Answer: No, we do not collect data from this app.

Rationale: FreePrint Studio processes selected images locally on device for preview, PDF export, and AirPrint. The app does not create accounts, upload selected images, call a backend service, use analytics, use advertising SDKs, or store user data on a developer-controlled server.

## Tracking

Tracking: No

Rationale: The app does not link user or device data with third-party data for advertising, measurement, or broker purposes.

## Third-Party SDKs

Third-party SDKs: None

Rationale: The current app uses SwiftUI, PhotosUI, UIKit printing/export surfaces, and local rendering. No third-party analytics, advertising, attribution, crash reporting, or payment SDK is included.

## Data Types

Data Types: None

Rationale: Selected images are user-provided local inputs for the immediate print workflow and are not collected by the developer.

## User Privacy Choices URL

Not applicable.

Rationale: The app does not collect data and does not provide account, server-side storage, deletion, or export workflows.
