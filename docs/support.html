FreePrint Studio Support

FreePrint Studio prepares selected images for exact-size PDF export and AirPrint.

Common Workflow

  1. Choose an image from Photos.
  2. Or tap Test Ruler to load a built-in six inch calibration ruler.
  3. Select a paper size and orientation.
  4. Enter the target printed width and height.
  5. Choose Fit, Fill, or Stretch placement.
  6. Export a PDF or open the system print sheet.

Exact-Size Printing

  • Confirm the printer is using the same selected paper size as FreePrint Studio.
  • In the printer options, choose Actual Size (100%) when available.
  • Avoid Fit to Page, Scale to Fit, or other automatic scaling options when exact dimensions matter.
  • For a new printer or paper stock, print the built-in Test Ruler first and compare the 0-6 inch marks.
  • If printer scaling cannot be controlled from AirPrint, export a PDF and print it from a desktop app that exposes scale settings.

Troubleshooting

  • If a printer is not visible, confirm it supports AirPrint and is on the same Wi-Fi network as your device.
  • If the printed size is unexpected, confirm the selected paper size and disable automatic scaling.
  • If an image looks cropped, switch from Fill to Fit before exporting or printing.
  • If a photo is missing, check iOS Settings for Limited Photos Access and allow access to the image you want to print.
