FreePrint Studio Support

FreePrint Studio prepares selected images for exact-size PDF export and AirPrint.

Common Workflow

  1. Choose an image from Photos.
  2. Select a paper size and orientation.
  3. Enter the target printed width and height.
  4. Choose Fit, Fill, or Stretch placement.
  5. Export a PDF or open the system print sheet.

Troubleshooting

  • If a printer is not visible, confirm it supports AirPrint and is on the same network as your device.
  • If the printed size is unexpected, check printer scaling options and choose actual size or 100 percent when available.
  • If an image looks cropped, switch from Fill to Fit before exporting or printing.
